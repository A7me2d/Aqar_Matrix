# Aqar Matrix Angular UI

Angular 22، TypeScript، Tailwind 3 وSCSS. واجهة RTL، وكل feature له ملفات HTML وSCSS وTS منفصلة.

## الحالة الحالية

هذه أول مرحلة فعلية في النقل: التطبيق الرئيسي والتنقّل والـ routes وحالة الاتصال مكتوبة بـ Angular. توجد routes مستقلة للأقسام ذات الأولوية، لكن واجهة العمل الداخلية لكل أداة ما زالت تستخدم تنفيذها الحالي داخل لوحة التحكم عبر إطار واحد مستمر. ليست هذه إعادة كتابة الأدوات بالكامل إلى Angular.

هذا الربط المؤقت يحافظ على الوظائف الحالية ويمنع إعادة تحميل إطار الأدوات عند كل تنقّل. لا يتم تغيير ملفات محرك السحب أو الإرسال أو النشر. الخطوة التالية هي تحويل محتوى الأقسام إلى Angular components واستبدال الربط المؤقت بخدمات بيانات مكتوبة الأنواع.

## الأقسام وترتيب النقل

1. `src/app/features/matches`: التطابق.
2. `features/sellers` و`features/buyers`: البائعين والمشترين.
3. `features/atlas`: الأطلس.
4. `features/recommendations`: رشّحلي.
5. `features/whatsapp`: بوت واتساب.
6. `features/facebook`: نشر فيسبوك.
7. `features/posts`: الطلبات والعروض، للاستفادة من الفصل السابق.

داخل كل فولدر: `*.component.html` و`*.component.scss` و`*.component.ts`. المكوّن الحالي يحدّد القسم ويعرض عنوانه في Angular، بينما الإطار المستمر يعرض وظائفه الحالية. أضف مكونات الكروت والفلاتر والخدمات داخل feature نفسه أثناء النقل، ولا تنقل منطق الأعمال إلى app.component.

## التشغيل أثناء التطوير

فعّل سيرفر المشروع الحالي على المنفذ 8787 أولًا. من `alaa-deals-app`:

```powershell
npm run dev:ui
```

افتح `http://localhost:4200`. إذا طلب تسجيل الدخول، استخدم «فتح لوحة التحكم» لتسجيل الدخول من نفس أصل التطوير، ثم «إعادة الاتصال». الـ proxy يمرر `/d/` و`/api/` إلى السيرفر الحالي، مع نفس الكوكي والداتا.

لو السيرفر على عنوان مختلف، اضبط `AQM_ENGINE_URL` قبل تشغيل الواجهة. لا توجهه لخدمة خارجية لا تخص المشروع.

## إخراج نسخة للتطبيق الحالي

من `alaa-deals-app`، عند الرغبة في تشغيل التجميع:

```powershell
npm run build:ui
```

يجمع Angular، وينسخ ناتج المتصفح إلى `re-hunter/angular/` ثم يعمل sync. بعد ذلك افتح `http://localhost:8787/d/angular/index.html`.

واجهة Electron القديمة تبقى المدخل الافتراضي حاليًا. Angular يستخدم السيرفر المحلي الموجود في هذه المرحلة؛ لم يتم تغيير ملف تشغيل Electron الافتراضي قبل اكتمال النقل والتحقق منه. `npm run sync` يظل نسخًا فقط ولا يشغّل Angular build.

## حدود الربط

- `core/models/feature.ts`: IDs وأسماء ومسارات الأدوات.
- `core/services/legacy-engine.service.ts`: الاتصال فقط، مع signals لحالة الربط والقسم المطلوب.
- `re-hunter/angular-bridge/`: الطرف الآخر من الربط، ويعمل فقط داخل الإطار الخاص بواجهة Angular.
- الرسائل تقبل نفس الأصل ونفس نافذة الإطار فقط، وتسمح بفتح أقسام محددة وطلب حالة الاتصال. لا يوجد تنفيذ كود أو أوامر مفتوحة عبر الرسائل.
- السكربت المستقل للوحة التحكم يستمر في العمل خارج Angular. CSS الدمج لا يتفعّل خارج الإطار.
- عند نقل أداة إلى Angular فعلًا، انقل ملكية بياناتها وأحداثها إلى service ومكوّنات داخل feature، ثم أزل اعتماد هذا القسم على الإطار. احتفظ بالإطار لباقي الأدوات إلى أن يكتمل نقلها.

لم تُشغّل اختبارات أو build عند إنشاء هذه المرحلة، حسب تعليمات صاحب المشروع.
